# Support

Create Fly: Villager Customers is supported through its issue tracker only, at https://github.com/cubealgos/create_villager_customers/issues. There is no service level:
issues are read and answered as time allows, and there is no guarantee of a fix or a date.

When reporting, include the Minecraft version, the Fabric Loader, Fabric API and Create Fly
versions, the mod version from the jar name, and the smallest set of steps that shows the problem.
A `latest.log` from the run helps more than a screenshot.

Security reports go through the same tracker; there is no private channel. The code on GitHub is a mirror of the Forgejo repository; the issues live on GitHub.
